📌 О проекте
Этот проект — моя первая серьёзная попытка сделать полноценную систему авторизации и управления пользователями сразу через два интерфейса: Telegram-бота и веб-сайт.

Коротко о сути:
Я разрабатываю шаблон, который можно использовать как основу для:

◾интернет-магазинов с Telegram-ботом

◾сервисов с поддержкой клиентов через бота

◾любых проектов, где нужна единая авторизация (бот + сайт)

Система автомитизцаии обработки клиентов для малого бизнеса

Состовляющая проекта:

1) Telegram-бот для клиентов
2) Backend API (FastAPI) - инфраструктура, логика и база данных
3) Web-панели администратора - управление заказами, клиентами и аналитикой
4) Система аналитики - статистика продаж и обращений

Backend:
Python, FastAPI, SQL (PostgreSQL)

TG Bot:
aiogram

Frontend
HTML, CSS, Jinja2 templates

Docker, JWT авторизация
