Бот для парсинга новостей

Получение новостей из источников: Bloomberg.ru, Kommersant.com, vtomske.ru

Для начала работы с телеграмм ботом, нужно скачать все зависиммости в окружение

Создать вертуальное окружение
python -m venv venv

Скачать все зависимости в окружение
python -m pip install -r requirements.txt

Для запуска бота нужно прописать команду
python -m app.main
